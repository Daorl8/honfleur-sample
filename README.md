# Honfleur — 데모 샘플 (이피웹)

남산 자락 프렌치 브런치·반려견동반 카페 옹플뢰르(honfleur_namsan) 가상 시안.

- 단일 파일 index.html(인라인 CSS/JS), 모바일 우선. 영문 메인 + 한글 소설명.
- 팔레트: 옅은 아이보리 #F7F5EE + 탁한 차콜 잉크 #22201B + 옅은 카키 포인트(소량). 검은 먹돌/자갈 텍스처(stone-*.png) 산포.
- 폰트: Cormorant Garamond(디스플레이) + Pretendard(본문·한글). CDN — ⚠️납품 시 self-host.
- 배포: Cloudflare Workers 정적자산. 데모 honfleur-sample.lgt3232.workers.dev.

## 확인·교체 대기
- 정확한 영업시간(현재 "월요일 휴무"만), 네이버 예약 정확 URL(현재 place/1122933127/booking 추정)
- 메뉴 실제 구성·가격, 반려견 동반 세부 정책
